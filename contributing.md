# CONTRIBUTING.md - O Manifesto do Pacto

Você chegou até aqui. Isso significa que você não quer apenas usar o SeerCat, você quer deixar a sua marca no abismo. Seja bem-vindo.

## As Regras do Pacto

Este não é um repositório corporativo. Não buscamos "clean code" vazio ou padrões engessados que matam a criatividade. Aqui, nós prezamos pela **identidade**.

### 1. Código com Alma
O SeerCat é uma extensão de quem o cria. Se você vai submeter um Pull Request, certifique-se de que ele não seja apenas funcional, mas que ele respeite a estética e a "lore" do projeto. Código bruto é bem-vindo, desde que seja honesto.

### 2. A Estética é Inegociável
Não tentem "limpar" a interface, remover os elementos visuais ou tornar o software genérico. A transparência, os gradientes vermelhos, o pentagrama e o caos visual são a assinatura desta ferramenta. Qualquer tentativa de "corporate-washing" será rejeitada.

### 3. O Macroverso (Easter Eggs & Lore)
Nós incentivamos o caos controlado. Quer adicionar um novo *easter egg*? Uma nova música para a trilha sonora? Uma animação nova para o gato? Faça. O SeerCat é um sistema de autor que aceita contribuições que adicionam profundidade e "vida" ao ecossistema.
